# The first playable sketch, with the base to build on

- The game: a complete mission from objective to report, in 3D, built by the team (menu, team of up to four on one
  screen, five scenarios, eight design steps, review, launch, month-by-month operation with events, report, ranking).
- One rulebook for every agent (`AGENTS.md`), the criteria of a lead agent (`docs/agents/lead.md`), the vision of the
  next version (`docs/design/vision.md`) and the design criteria (`docs/design/criteria.md`).
- The project's state and architecture (`docs/STATE.md`, `docs/architecture.md`), the challenge material
  (`docs/challenge/`), the team's notes and pitch outline (`docs/team/`), and the knowledge base (`kb/`).
- CI on every push (import, a headless run of the main scene, the fuzz test, the web export), a release workflow that
  tags each merged version, a pull request template, and scripts for people and agents in `tools/`.
- The web export preset (single-threaded, runs on any static host), one line ending for every system, and no AI
  co-author lines in commits.
